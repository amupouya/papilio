# Papilio 4.0.0

`PermutedBigIntField` generates a nonsequential BIGINT directly in any PostgreSQL
column. Set `primary_key=True` or `unique=True` when needed. Use it on BaseEntity,
or override `id` on IdentifiedEntity/PersistenceEntity to retain the existing
ready PostgreSQL repositories, foreign keys and ordinary BaseOutput schemas.

SQLAlchemy manages fresh sequence lifecycle with the field's table. Alembic
revisions include explicit sequence/default/ownership DDL. Loaded model writes
retain their database-assigned identity for upsert.

See the [field guide](../guide/permuted-fields.md) for setup and examples.
Existing database identifiers and dependent references require an explicit
application migration before changing their schema or generation rules.
